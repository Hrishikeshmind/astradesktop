Astra Browser

Features

A Firefox-based desktop browser with a vertical sidebar, workspaces, and Astra-specific chrome. This page is the in-app stand-in for a marketing site that is not live yet.

Sidebar and tabs

  • Only Sidebar, Sidebar + Top Toolbar, and collapsed icon rail
  • Compact Mode to tuck chrome until you hover the edge
  • Workspaces and split view from the Zen lineage

New Tab

  • Minimal overlay: type and go, previous tab stays put
  • Search Hub layout when you want a fuller start page

AI Sidebar

Optional chatbot panel (Claude, ChatGPT, Copilot, Gemini, Le Chat). Nothing is sent until you pick a provider and use the panel.

Contribute

Source and issue tracking live on GitHub. That is the right place for code and bug reports.
