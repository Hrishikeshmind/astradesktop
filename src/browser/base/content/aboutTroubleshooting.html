Astra Browser

Troubleshooting

If Developer Tools or extension debugging behaves unexpectedly, start with these checks before filing a bug.

Version mismatch

Remote debugging expects the browser and DevTools to come from the same build family. If you connect to another device or an older build, update both sides to the latest Astra release when possible.

Quick fixes

  • Restart Astra after installing or updating extensions.
  • Open about:support and attach that page when reporting an issue on GitHub.
  • Try Troubleshoot Mode from the Help menu if an extension may be interfering.

Report a bug

File issues at GitHub with steps to reproduce and your Astra version from about:about.
