# Privacy-Related Features in Astra

This page covers privacy-adjacent settings where **Learn more** links in Astra point for plain-language help — including link previews, recommendations, and related controls.

## Link previews

Link previews show a short summary when you long-press or hover a link (where the feature is available). They run **on your device** using local models when enabled; Astra does not send the full page to a cloud service for this feature.

**Where to control it:** Settings → Privacy & Security (and AI-related controls where shown).

- You can turn link previews off entirely.
- Opt-in prompts appear before first use on supported sites.

## Extension and feature recommendations

Astra disables Mozilla’s promotional **Recommendations** pane in the add-ons manager. Optional recommendation toggles in Settings (if visible) control whether Firefox’s CFR (Contextual Feature Recommender) may suggest extensions or features — not ads from Astra.

Astra’s own **Recommended extensions** list in Look and Feel is a curated install helper that links directly to [addons.mozilla.org](https://addons.mozilla.org/) — not a tracking feed.

## Tracking protection and presets

Astra includes **privacy presets** (Strict / Balanced / Maximum) under Settings → Look and Feel → Privacy presets. These adjust tracking protection, cookie behavior, and related shields together.

For the full in-product privacy notice, open **Help → About Astra → Privacy Notice** (`about:astra-privacy`).

## Telemetry and data collection

Astra aims to minimize phone-home behavior compared with stock Firefox. Settings → Privacy & Security lists what data collection toggles remain (crash reports, studies, etc.) and lets you turn them off.
