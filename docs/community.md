# Astra Community

Astra is an open-source browser built on Firefox technology. Here is how to participate, get help, and follow the project.

## Get help

| Need | Where |
| --- | --- |
| Bug reports | [GitHub Issues](https://github.com/Hrishikeshmind/astradesktop/issues/new?labels=bug) |
| Ideas and feedback | [GitHub Issues (enhancement)](https://github.com/Hrishikeshmind/astradesktop/issues/new?labels=enhancement) |
| Releases and changelog | [GitHub Releases](https://github.com/Hrishikeshmind/astradesktop/releases) |
| Add-ons help | [Add-ons support](./addons-help.md) |

## Contribute

See the [contributing guide](./contribute.md) in this repository for branch structure, build pointers, and the code of conduct.
