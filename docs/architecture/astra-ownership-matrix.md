## Ownership rules (binding)

- **Firefox** owns mature native backends (PDF.js, translations, DevTools, policies, DRM/CDM, updater, permissions, Places, Sync/FxA, etc.).
- **Zen** owns vertical tabs, sidebar, Spaces, split view, folders, Glance, compact mode, and related session coordination.
- **Astra** owns discoverability, integration UX, India-specific product surfaces, App Hub, Suraksha, transparent mode, persona UX, and clearly isolated Astra managers.
- Astra is **not** the owner of native password storage, migration engines, profiles databases, PDF.js, translations, DevTools, EnterprisePolicies, DRM/CDM, network security, or updater backends.
- `NATIVE_ONLY`: native subsystem is implementation + state owner.
- `ASTRA_ENTRYPOINT`: Astra owns only discoverability.
- `ASTRA_UX_WRAPPER` / status shells: Astra owns shell; native owns backend.
- `DEEP_INTEGRATION`: one canonical coordinator; multiple writers on one state row remain CONFLICT until resolved.
